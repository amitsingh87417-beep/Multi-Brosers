# Multi Tap Browser — Pro Workspace v5.0

## What's New in v5.0
- **1 to 1,00,000 (1 Lakh) Tabs Launcher:** Paste one link at the top, pick any tab count from `1` up to `1,00,000` (with 1-tap presets for 2, 4, 6, 10, 25, 50, 100, 500, 1,000, 10,000, and 1,00,000), and tap **Open Tabs**.
- **Smart Virtual Pagination (Zero Hang):** Instead of crashing your phone by rendering thousands of iframes at once, tabs load cleanly in smooth pages (`2 / 4 / 6 / 8 / 12` live screens per page) with **Prev / Next**, **Jump to Tab #**, and **Auto Next Page** timer.
- **YouTube Black Screen Fix:** Added `referrerpolicy="strict-origin-when-cross-origin"` and proper embed parameters so YouTube & YouTube Shorts play cleanly on Vercel and mobile Chrome.
- **Adsterra Ready Banner Slots:** Clean, non-intrusive Top Banner and Bottom/Native Banner containers built right into `index.html`—no annoying popups.

## How to Add Your Adsterra Ads
1. Open `index.html` in Acode or GitHub editor.
2. Search for `PASTE YOUR ADSTERRA TOP BANNER SCRIPT` and paste your Adsterra Banner `<script>` code there.
3. Search for `PASTE YOUR ADSTERRA NATIVE OR BOTTOM BANNER SCRIPT` and paste your Adsterra Native Banner `<script>` code there.
4. Save and push to GitHub—Vercel will auto-deploy.
